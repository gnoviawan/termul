---
title: AI agents
description: Chat with an AI coding agent that reads, edits, and runs code in your project.
---

An agent is an AI coding tool, such as Claude Code, Codex, or Gemini CLI. Troupe starts the agent for you and gives it a chat window. You ask for a change in plain words. The agent reads your files, edits them, and runs commands in your project. You watch each step and approve the risky ones.

![A chat in Troupe. The agent's plan is at the top, its reply is in the middle, and the message box is at the bottom.](/screenshots/agents-chat.png)

Each chat belongs to a project. A chat keeps running when you switch to another project or tab, so you can start a long task and come back to it later.

<Callout type="info">
  To install an agent, sign in to it, or give it MCP servers and skills, see [Set up agents](/docs/agent-setup).
</Callout>

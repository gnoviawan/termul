---
title: Find and reopen chats
description: Search your chats, pick up an old conversation, import chats from another client, open a chat next to another one, or delete it.
---

Troupe saves every chat with its project. The **Chats** tab in the side panel lists them, newest activity first, so you can return to any conversation and carry on where you left off.

![The Chats tab lists several chats. A menu is open on one of them with Open in split, Open Terminal Here, Open in File Explorer, Copy Path, and Delete Chat.](/screenshots/agents-chat-menu.png)

## Read a chat card

Each card in the list shows:

- The chat's title. It starts as the first line of your first message, cut to 48 characters. Some agents give the chat a new title later.
- What the chat is doing. A spinner means the agent is working. **Needs you** means it waits for your answer. A dot with **New** marks a reply you have not seen. Otherwise, the card shows how long ago the chat was last active.
- The agent's icon, the model, and the git branch the chat works on.

A chat that ended with an error shows **Failed**. A closed chat has a dimmed title and shows **Closed** before the time.

The list shows the chats of the active project. The menu at the top of the side panel narrows it. It lists the project folder and each worktree by branch name. Pick a worktree to see only the chats that run in it. Pick the project folder's row, for example **main**, to see all of them.

## Search your chats

Type in **Search chats…** at the top of the list. The search matches the chat title, the agent name, the model, and the branch. To clear it, click the **X** in the box or press `Esc`.

To move through the list with the keyboard, click or tab to a card, then use the up and down arrow keys.

## Reopen and resume a chat

Click a card to open the chat in the current pane. If the chat is already open in a tab, Troupe switches to that tab instead. If the chat is still running, you are back in the conversation right away.

A chat that sits idle stops after a while. Its history stays. To pick it up again, start typing or send a message. Troupe starts the agent again and shows "Resuming chat…". A message you send waits in the queue until the agent is back.

If Troupe cannot resume the chat on its own, a bar says "This chat stopped." Click **Resume chat** to try again.

To change how long an idle chat stays open, go to **Settings** > **Agent chats** > **Close idle chats after**. The default is 30 minutes. A chat that is working or waiting for your answer stays open.

Some agents cannot reload an old conversation. With those agents you can read the chat, but you cannot continue it. Start a new chat instead.

## Import chats from outside Troupe

Chats you had with an agent outside Troupe, for example in the Claude Code CLI, can join your chat history. Troupe asks the agent for the chats it keeps for the current folder and copies the ones you pick, with their messages and tool activity.

1. In the **Chats** tab, click the **Import chats** button next to **Search chats…**. On a phone, tap **Import chats** below the chat list in **Recents**.
2. If you have more than one agent set up, pick one under **Agent**. The dialog starts with Claude Code when you have it.
3. Check the chats you want, or check the **All … chats** box at the top to take every one. Each row shows the chat's title and when it was last active.
4. Click **Import**. The button shows how many chats you picked.

Troupe imports the chats one at a time and shows its progress, for example "Importing 2 of 5…". To stop, click **Stop import**. The chat in progress finishes, and no other one starts. If a chat fails, the row says why, and the others still import. Click **Try again** to retry the ones that failed.

An imported chat appears in the list as a closed chat, with the time it was last active in the other client. Open it and send a message to continue it, the same way you [resume a chat](#reopen-and-resume-a-chat). A chat you already imported does not show up in the dialog again.

The dialog lists the chats of the folder the Chats tab shows, so pick a worktree in the menu at the top of the side panel to import its chats. Some agents cannot list and load their chats. For those, the dialog says there is nothing to import. When you use Troupe through a server that does not allow changes from your device, the button is off. Hover it to see why.

## Open a chat next to another one

Right-click a card and choose **Open in split**. The chat opens in a new pane to the right of the active pane, so you can watch two chats at once. You can also drag a card onto a pane.

**Open in split** is off when the chat is already the only tab in the active pane.

## Open the chat's folder

Each chat works in a folder, which is your project folder or a worktree. Hover a card and click the terminal button to open a terminal in that folder. The right-click menu also has:

- **Open Terminal Here**. Same as the terminal button.
- **Open in File Explorer**. Shows the folder in your system's file manager. In a browser, Troupe copies the path instead.
- **Copy Path**. Copies the folder path.

## Let an agent read another chat

To give an agent the history of an earlier chat, even one from another project, copy the chat's reference and paste it into your message.

1. Right-click the chat's card and choose **Copy Chat Reference**.
2. Paste it into the chat where you want the agent to read it.

The reference is a few lines of plain text: the chat's title, its chat ID, its project and folder, and a hint to read it with the `read_chat` tool. Every agent in Troupe has that tool. It reads the chat as plain text, oldest message first, a page at a time. If the chat switched agents, the agent reads the whole conversation. For each tool call, the agent sees only its kind, the files it changed and its status, not its output.

To copy only the ID, choose **Copy Chat ID** instead. On a phone, long-press a chat in **Recents** and tap **Copy chat reference**.

## Delete a chat

1. Right-click the card and choose **Delete Chat**.
2. Click **Delete** to confirm.

Deleting a chat removes it and its history, and closes its tab. For a chat that [switched agents](/docs/agents/switch-agents), this deletes the whole conversation, with every agent's part. In the desktop **Chats** list, if the chat switches agents while the confirmation is open, the dialog says the chat changed and asks you to confirm again. You cannot undo it. The files the agent changed stay as they are.

## Restart a chat's agent

After you change an agent's settings, such as its MCP servers or skills, a running chat still uses the old ones. To apply them, right-click the chat's tab and choose **Reload this chat**. Troupe restarts the agent for this chat and keeps the conversation. It does not send your last message again.

When background agents or commands of the chat are still running, Troupe asks you to confirm the reload, because the reload stops them.

**Reload this chat** is off while the agent is working, waiting for you, or has queued messages. It is also off for a stopped chat and for agents that cannot reload a conversation. When the message box shows an **MCP** badge, its popover has the same **Reload this chat** button.

## Link to a chat

<Callout type="info">This works in the browser only.</Callout>

When a chat is open, the browser's address bar holds a link to it that ends in `#/c/` and the chat's id. Bookmark the link, or open it in another tab, to go straight to that chat. The link opens the chat in its own project, even if a different project is active. If you reload the page, the same chat opens again.

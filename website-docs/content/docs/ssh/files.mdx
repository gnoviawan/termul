---
title: Work with remote files
description: Browse, upload, download, rename, delete, and edit files on a server.
---

<Callout type="info">This works in the desktop app only.</Callout>

While a session is connected, the **Files** panel shows the server's files next to the terminal. It uses the same connection as the session, so you don't sign in again. This kind of file access is called SFTP.

## Open the Files panel

1. [Connect to a host](/docs/ssh/connect).
2. Select the session tab. The **Files** panel opens next to it and starts in your home folder on the server.

If you don't see the panel, press `Ctrl+B` (`Cmd+B` on macOS) to show the side panel.

## Browse folders

- Click a folder to expand it in place. Click it again to collapse it.
- Click **Up one folder** to go to the parent folder.
- Click a part of the path above the list to jump to that folder.
- Click **Refresh** to load the list again.

Each row shows the size and the time of the last change. Click a row to see its full details at the bottom of the panel: the permissions, the size, and the full date.

## Upload files

To upload with the file picker:

1. Click **Upload** in the panel's toolbar.
2. Choose one or more files on your computer.

To upload with drag and drop, drag files from your computer onto the **Files** panel. The panel shows **Drop to upload** and the folder the files go to. To upload into a subfolder, drop the files on that folder's row.

If a file with the same name already exists on the server, Troupe asks before it replaces it. Click **Replace** to overwrite the file, or **Cancel** to stop.

The **Transfers** list at the bottom of the panel shows the progress of each upload and download. Click **Clear finished** to remove the completed ones.

## Download a file

1. Hover the file's row.
2. Click **Download**.
3. Choose where to save the file on your computer.

Only files have a **Download** button. You can't download a folder.

## Create a file or a folder

1. Click **New file** or **New folder** in the panel's toolbar.
2. Type a name.
3. Click **Create**.

Troupe creates the item in the folder shown in the path above the list.

## Rename or delete a file or a folder

Hover the row, then click a button:

- **Rename** opens a dialog. Type the new name and click **Rename**.
- **Delete** asks you to confirm. You can't undo a delete. Troupe deletes only empty folders, so delete a folder's contents first.

## Edit a remote file

1. Click a file in the **Files** panel. The file opens in the editor, in place of the terminal. The session keeps running.
2. Edit the file.
3. Click the save button, or press `Ctrl+S` (`Cmd+S` on macOS). Troupe writes the file back to the server.
4. Click the close button to return to the terminal.

If you close the file with unsaved changes, Troupe asks what to do. Click **Save**, **Discard**, or **Keep editing**. To open another file, save or discard your changes first.

You can edit text files up to 5 MB. For a larger file or a file that is not text, download it instead.

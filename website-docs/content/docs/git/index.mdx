Termul has Git built in. You can review what changed, commit it, and push it without leaving the app. Worktrees let you and your agents work on several branches at the same time.

Most Git actions start in the **Changes** tab of the side panel.

## What Termul does not do

Termul does not pull, fetch, or merge branches locally, and it has no screen for resolving merge conflicts. Use Git in a [terminal](/docs/terminals) for those.

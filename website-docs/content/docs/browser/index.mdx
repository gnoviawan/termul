---
title: Browser and canvas
description: Preview web pages next to your code, mark them up for an agent, and edit your project's design file.
---

Termul can show web pages and designs in the same window as your terminals, files, and chats. You can check your app in a browser tab while an agent changes the code, or open your project's design file on a canvas.

The browser features work in the desktop app only. The canvas also works in the browser version of Termul.

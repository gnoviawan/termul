---
title: Agent setup
description: Install AI agents, connect your Claude accounts, and give agents extra tools and skills.
---

Troupe can chat with many AI coding agents, such as Claude Agent, Codex, Gemini CLI and OpenCode. This section shows you how to get an agent ready, how to add your own, and how to give agents more tools. To learn how to use chats once an agent is ready, see [Agents](/docs/agents).

Most setup happens in Settings. Open it with `Ctrl+,` (`Cmd+,` on macOS), or click **Settings** at the bottom left of the window.

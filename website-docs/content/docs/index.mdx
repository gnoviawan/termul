Troupe is a workspace for your coding projects. Each project gets its own terminals, chats with AI coding agents, file explorer and editor, and Git tools. You can keep many projects open and switch between them. A project you leave keeps running in the background.

![Troupe with the acme-shop project open: the projects list on the left, the Chats tab in the side panel, and an agent chat that shows its plan and the files it changed](/screenshots/overview-hero.png)

## Three ways to use Troupe

- **The desktop app** runs on macOS, Windows, and Linux. It is called **Troupe**. See [Install Troupe](/docs/getting-started/install).
- **In a browser.** `troupe-server` runs Troupe on a Linux machine, such as a home server or a cloud computer. You open it in a web browser from anywhere. The terminals, agents, and files stay on the server. See [Browser and phone](/docs/remote).
- **On your phone.** Open the browser version on your phone, and Troupe switches to a layout made for small screens. The desktop app can also share a view-only link to itself. See [Browser and phone](/docs/remote).

![Troupe on a phone, showing an agent chat in the acme-shop project](/screenshots/overview-phone.png)

The desktop app and the browser version look and work almost the same. Where a feature works in only one of them, these docs say so.

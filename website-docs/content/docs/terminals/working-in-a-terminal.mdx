A Troupe terminal works like the terminal you already use. This page covers the parts that are specific to Troupe.

## Type commands in the command editor

In a local terminal on macOS or Linux whose shell is Bash or Zsh, you type commands in a command editor at the bottom of the terminal instead of on the shell's own prompt line. The terminal output stays above it. This works in the desktop app and in a browser connected to Troupe.

Above the editor, chips show the terminal's working directory and its Git branch.

The editor appears only while the shell waits for a command. When you run a command, the editor goes away and your keys go straight to the program, so interactive programs such as `vim`, `less`, or an AI coding agent work as usual. The editor comes back at the next prompt.

Troupe doesn't use the command editor on Windows, for other shells such as fish or PowerShell, or for terminals that run a program such as an AI coding agent. If Troupe can't set up the editor when the shell starts, the terminal works the normal way. There is no setting to turn the editor off.

### Keys in the command editor

| Key | What it does |
| --- | --- |
| `Enter` | Runs the command. |
| `Shift+Enter` | Starts a new line in the editor without running the command. |
| `Tab` | Asks your shell for completions and opens a list of them. Press `Tab` again to insert the highlighted one. |
| `Up`, `Down` | With the list open, move through the completions. Otherwise, go back and forward through commands you ran in this project that start with what you typed. In a command with several lines, they move between lines first. |
| `Right` | At the end of the line, inserts the highlighted completion that shows as gray text after the cursor. |
| `Esc` | Closes the completion list. |
| `Ctrl+C` | Copies the selected text, in the editor or in the terminal output. With nothing selected, clears the editor. |
| `Ctrl+D` | Deletes the character after the cursor. In an empty editor, sends end-of-input to the shell, which usually closes it. |
| `Ctrl+A`, `Ctrl+E` | Move to the start or end of the line. |
| `Ctrl+K`, `Ctrl+U`, `Ctrl+W` | Delete to the end of the line, to the start of the line, or the word before the cursor. |
| `Ctrl+Z` (`Cmd+Z` on macOS) | Undoes the last edit. `Ctrl+Y` redoes it. On macOS, redo is `Cmd+Shift+Z`. On Linux, `Ctrl+Shift+Z` also works. |

Troupe's own shortcuts still come first. For example, on Windows and Linux `Ctrl+K` opens the command palette and `Ctrl+W` closes the tab, as listed in [Keys that don't reach your shell](#keys-that-dont-reach-your-shell).

When you paste into the editor, Troupe removes control characters from the text. Text you typed but didn't run stays in the editor if you switch to another terminal and back. The editor uses the terminal's font size, with a minimum of 16 pixels on touch screens.

## Copy and paste

- **Copy.** Select text with the mouse, then press `Ctrl+C` (`Cmd+C` on macOS).
- **Paste.** Press `Ctrl+V` (`Cmd+V` on macOS).
- **Select everything.** Press `Ctrl+A` (`Cmd+A` on macOS).

`Ctrl+C` copies only when text is selected. With nothing selected, `Ctrl+C` goes to the program, so it stops the running command as usual. On macOS, `Ctrl+C` always stops the command, and `Cmd+C` copies.

Selecting text doesn't copy it. Use `Ctrl+C` or the right-click menu.

In the desktop app, if the clipboard holds an image, `Ctrl+V` passes the key on to the program instead of pasting text. Command-line tools that read images from the clipboard, such as AI coding agents, can then pick up the image.

### Right-click menu

Right-click in a terminal to open its menu. Right-clicking also selects the word under the pointer.

![The terminal right-click menu with Copy, Paste, Select All, Explain with AI, Fix Command with AI, and Restart Terminal](/screenshots/terminals-right-click.png)

**Copy**, **Explain with AI**, and **Fix Command with AI** need selected text. For the two AI actions, see [Ask AI about terminal output](/docs/terminals/ai-help).

If you open Troupe in a browser over plain `http://` from another computer, the browser blocks clipboard access. **Paste** in the menu then does nothing, but `Ctrl+V` still pastes.

## Keys that don't reach your shell

Most keys go straight to your shell, including `Tab` for completion and readline keys such as `Ctrl+E`, `Ctrl+P`, `Ctrl+L`, and `Ctrl+D`. Troupe's own shortcuts come first, though, even when a terminal has focus. While you type in the [command editor](#type-commands-in-the-command-editor), the editor handles the keys listed there.

### Windows and Linux desktop app

These keys don't reach your shell:

| Key | What happens instead |
| --- | --- |
| `Ctrl+A` | Selects all terminal text. |
| `Ctrl+B` | Nothing. |
| `Ctrl+C` | Copies, if text is selected. With no selection, the shell gets it. |
| `Ctrl+F` | Nothing. Troupe has no terminal search. |
| `Ctrl+K` | Opens the command palette. |
| `Ctrl+N` | Opens the new project dialog. |
| `Ctrl+R` | Opens the [Command History](#command-history) window instead of your shell's history search. |
| `Ctrl+S` | Nothing in the terminal. Troupe keeps this key for saving files. |
| `Ctrl+T` | Opens the agent launcher. |
| `Ctrl+U` | Nothing. |
| `Ctrl+V` | Pastes. |
| `Ctrl+W` | Closes the tab. |
| `Ctrl+=`, `Ctrl+-`, `Ctrl+0` | Zooms the whole window. |
| `Ctrl+,` | Opens Settings. |
| `Delete`, `F2` | Nothing. These keys are the shortcuts for **Delete Files** and **Rename File** in the Explorer. To delete the character under the cursor, press `Ctrl+D` instead. |

Troupe also uses some `Ctrl+Shift` and `Ctrl+Alt` keys, such as `Ctrl+Shift+P` for the command palette and `Ctrl+Alt+T` for the theme picker. **Settings** > **Keyboard Shortcuts** lists them all.

### macOS

Troupe's shortcuts use `Cmd`, so your shell gets the `Ctrl` keys. A few keys still don't reach the shell. `Delete` (the forward-delete key) and `F2` do nothing, as on Windows and Linux. In the desktop app, `Ctrl+U` also does nothing.

### In a browser

The browser version moves some shortcuts to `Alt`, because browsers keep keys such as `Ctrl+W` and `Ctrl+T` for themselves. For example, **Close Tab** is `Alt+W` and the agent launcher is `Alt+T`.

In a browser, these keys don't reach your shell:

- `Ctrl+A`, `Ctrl+B`, `Ctrl+C` with a selection, `Ctrl+F`, `Ctrl+K`, `Ctrl+S`, and `Ctrl+V`, as in the table above.
- `Delete` and `F2`.
- The `Ctrl+Shift` and `Ctrl+Alt` shortcuts, as in the desktop app.
- The `Alt` shortcuts: `Alt+N`, `Alt+T`, `Alt+W`, `Alt+PageUp`, `Alt+PageDown`, `Alt+=`, `Alt+-`, `Alt+0`, and `Alt+,`.

Troupe doesn't bind `Ctrl+R` or `Ctrl+U` in a browser, so your shell gets them. Your browser may keep `Ctrl+W`, `Ctrl+T`, and `Ctrl+N` before Troupe or the shell sees them.

### Give a key back to your shell

To free a key that Troupe uses as a shortcut, open **Settings**, select **Keyboard Shortcuts**, and record a different key combination for that shortcut. For example, record another key for **Delete Files** to get `Delete` back. You can't remove a shortcut. `Ctrl+A`, `Ctrl+C`, `Ctrl+V`, and `Ctrl+U` aren't in the list, so you can't give them back.

### Shift+Enter

`Shift+Enter` sends a line feed, the same as `Ctrl+J`. AI coding agents that run in a terminal, such as Claude Code, use it to start a new line in a prompt without sending it. When the [command editor](#type-commands-in-the-command-editor) isn't active, a plain shell treats it like `Enter` and runs the command. In the command editor, it starts a new line.

## Open links and files from the output

Hold `Ctrl` (`Cmd` on macOS) and click a web address or a file path in the terminal. A plain click does nothing.

- **Web addresses.** Troupe opens `http` and `https` links. Other kinds of links show an error message.
- **File paths.** Troupe opens the file in its editor. If the file is already open, Troupe switches to its tab. If the path ends in a line number, such as `src/cart.ts:12`, `src/cart.ts:12:5`, or `src/cart.ts#L12`, the editor jumps to that line.

A file path needs at least one `/` or `\`. A bare name such as `cart.ts:12` is not a link. Troupe looks up a relative path from the terminal's folder and from the project folder. The file must be inside one of those folders.

To choose where web links open:

1. Open **Settings** and select **Behavior**.
2. In **Open Terminal Links In**, choose **System Default Browser** or **Troupe Browser**.

**System Default Browser** is the default. **Troupe Browser** opens the link in a browser tab inside Troupe, which only the desktop app has. In a browser, keep **System Default Browser**. Troupe then opens the link in a new browser tab.

## Change the look and the scrollback

Open **Settings** and select **Terminal Appearance**.

- **Font Size** sets the terminal text size, from 10 to 24 pixels. The default is 14, and open terminals change right away.
- **Scrollback Buffer Size** sets how many lines each terminal keeps for scrolling back: 1,000, 5,000, 10,000, 25,000, or 50,000. The default is 10,000. More lines use more memory.
- **Terminal Renderer** picks how terminals draw text. **Auto** is the default and uses your graphics card when it can. The other options are **WebGL** and **DOM**. Try **DOM** if text looks wrong.
- **Screen reader mode** makes terminal output readable by screen readers. It is off by default.

Scrollback and screen reader changes apply to terminals you open after the change.

![The Terminal Appearance section with UI Zoom Level, Font Size, Scrollback Buffer Size, Terminal Renderer, and Screen reader mode](/screenshots/terminals-appearance-settings.png)

## Get notified when a long task finishes

Troupe can tell you when a long-running terminal goes quiet, for example when a build or an AI agent finishes. The setting is **Notify when a terminal agent finishes**, under **Behavior** > **Notifications** in **Settings**. It is on by default.

A terminal counts as finished when it printed output for at least 20 seconds and then stayed quiet for 8 seconds. Troupe doesn't notify you about the terminal you are looking at while the Troupe window has focus. The notification shows the project name and says that the terminal's agent finished.

Troupe also notifies you when the shell in a terminal exits, for example after you type `exit`. The message says **DONE**, or **Failed** with the exit code. This notification has no setting. Troupe doesn't send it for terminals that you close yourself.

In a browser, Troupe uses browser notifications, and the browser asks for permission the first time. Select a notification to go to that terminal. In the desktop app, these are system notifications. Selecting one brings the Troupe window to the front.

When a terminal you aren't looking at finishes, its pane also gets an amber outline. The outline goes away when you click in the pane or type in it.

## Command history

The **Command History** window lists commands you ran in Troupe terminals, so you can find one and insert it again.

<Callout type="info">
  Troupe records only commands you run from the [command editor](#type-commands-in-the-command-editor). Terminals without the editor, for example on Windows, add nothing to the list. Use your shell's own history there, for example the `Up` arrow key or the `history` command.
</Callout>

To open the window:

- In the desktop app, press `Ctrl+R` (`Cmd+R` on macOS).
- In a browser, open the command palette and run **Command History**. `Ctrl+R` goes to your shell there.
- On a phone, select the **...** button at the top of a terminal, then **Command history**.

The window has a search box and a filter for **This Project** or **All Projects**. Select a command or press `Enter` to insert it at the prompt, or in the command editor. Troupe doesn't run it. **Clear History** deletes the list for the current project.

## Choose what the context bar shows

The context bar runs along the bottom of the window. It shows facts about the active project and terminal. Its **Terminal** button opens a new terminal in the active folder.

To choose what the bar shows, select the gear icon at the right end of the bar (**Context bar settings**), then turn items on or off.

![The Show in Context Bar menu with switches for Project Name, Git Branch, Git Status, Working Directory, and Exit Code](/screenshots/terminals-context-bar.png)

- **Project Name** shows the project's name. Off by default.
- **Git Branch** shows the current branch. Select it to switch to another branch or create one. On by default.
- **Git Status** shows how many files are modified, staged, and untracked, when there are any. Off by default.
- **Working Directory** shows the active project or worktree folder. On by default.
- **Exit Code** shows whether the last command in the active terminal succeeded. On by default. It appears only if your shell reports exit codes to the terminal. Terminals with the [command editor](#type-commands-in-the-command-editor) do this. Other shells often don't unless you set up shell integration.

Troupe saves your choices with your settings. Every browser and phone that connects to the same Troupe uses them.

## Use a terminal on your phone

When you open Troupe in a phone browser, open the menu, select **Terminals**, and select **New terminal**. A row of keys above the keyboard gives you the keys a phone keyboard lacks: **Esc**, **Tab**, **Ctrl+C**, the arrow keys, **PgUp**, and **PgDn**. It also has a **Paste** button. Select the keyboard icon at the start of the row to hide or show the keys. **Paste** stays visible.

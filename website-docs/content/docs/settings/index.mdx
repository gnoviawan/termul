title: Settings
description: Change how Troupe looks and behaves, for the whole app or for one project.
---

Troupe has two kinds of settings. App settings apply everywhere: the terminal font size, the default shell, keyboard shortcuts, notifications, and updates. Project settings apply to one project: its name, folder, color, environment variables, and shell.

## Open app settings

Use one of these:

- Press `Ctrl+,` (`Cmd+,` on macOS). In the browser version, press `Alt+,`.
- Select the **Settings** button at the bottom left of the sidebar.
- Open the command palette with `Ctrl+K` and choose **App Preferences**.

![The Application Preferences window with its list of tabs on the left](/screenshots/settings-app-preferences.png)

The tabs are on the left. To find one option, type in **Search settings** above the tabs.

## Open project settings

1. Right-click the project in the sidebar.
2. Select **Settings**.

You can also open the command palette and choose **Project Settings**. That opens the settings of the project you have open.
